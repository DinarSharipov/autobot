# Статус E2E-тестов

Последнее обновление: 2026-10-16

Локальные quality gates последнего прогона: **Готово** — `locales:check`, `format:check`, `lint`,
`typecheck`, `build`, `git diff --check`.

Ограничение текущего live-прогона: Telegram Desktop отображается как запущенный, но окно не
доступно через CUA после зависания предыдущей сессии. Поэтому новые Telegram E2E-кейсы не отмечены
как успешно пройденные без фактической проверки интерфейса.

Статусы:

- **Готово** — сценарий реализован и успешно пройден вручную.
- **Не проверено** — сценарий реализован или запланирован, но ручной прогон не завершён.
- **Ошибка** — сценарий проверен и выявлена проблема; ниже обязательна ссылка на issue/описание.

## Известные ошибки

Ошибок реализации по текущему локальному прогону не выявлено. Недоступность окна Telegram —
ограничение тестовой среды, а не подтверждённая ошибка бота. Если live-проверка выявит дефект,
изменить статус на **Ошибка**, добавить дату, описание воспроизведения и ссылку на issue или commit.
